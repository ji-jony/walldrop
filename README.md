# WallDrop — Free 4K Wallpaper Website

## Your files:
- `index.html` → Main website (homepage + wallpaper grid)
- `admin/index.html` → Admin dashboard

## How to go LIVE (free):

### Step 1: Go to github.com → Sign up free

### Step 2: Create new repository
- Name it: `walldrop` (or anything)
- Set it to: Public

### Step 3: Upload these files
- Click "uploading an existing file" in your repo
- Drag `index.html` and the `admin/` folder
- Click "Commit changes"

### Step 4: Enable GitHub Pages
- Go to repo Settings → Pages
- Source: main branch → Save
- Your site is LIVE at: https://yourusername.github.io/walldrop

### Step 5: Get free API keys (for real 4K wallpapers)
- Unsplash: https://unsplash.com/developers
- Pexels: https://www.pexels.com/api/
- Replace `YOUR_UNSPLASH_ACCESS_KEY` in index.html

### Step 6: Apply for Google AdSense
- https://adsense.google.com
- Add your live site URL
- Paste their code in index.html <head>
- Wait for approval (1-14 days)
- Start earning!

## Cost: $0 forever
